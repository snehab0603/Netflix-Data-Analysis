# Netflix Data Analysis

## 📌 Project Overview

This project analyzes the Netflix Movies and TV Shows dataset to understand the content available on Netflix.

The analysis focuses on content types, genres, countries, release years, ratings, and other useful patterns in the dataset.

## 🎯 Objectives

- Analyze the distribution of Movies and TV Shows
- Identify the most common genres
- Analyze content by release year
- Explore Netflix content by country
- Analyze ratings and duration
- Identify interesting trends and insights
- Create meaningful visualizations from the data

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- GitHub

## 📂 Dataset

The dataset contains information about Netflix Movies and TV Shows, including:

- Title
- Type
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed In
- Description

## 📊 Analysis

The project will include data cleaning, exploratory data analysis (EDA), visualizations, and key insights from the Netflix dataset.
